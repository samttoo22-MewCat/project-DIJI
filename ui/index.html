ABOUT THE PROJECT

不只是聊天，是一起續寫。

DIJI 是一個非商業、可自架的角色互動專案。從人設創作到長短對話，將角色、對話與記憶串在一起，讓每段互動都能繼續。

01 / 創作

有性格的角色

從角色庫選擇，或從一個靈感生成並編輯自己的人設。

02 / 延續

接得上的對話

長對話鋪陳故事，短對話輕鬆來回；登入後保存對話與記憶。

03 / 選擇

自己的模型額度

連接 BazaarLink 或 OpenRouter，自選模型與額度使用順序。

安裝 DIJI

加入 iPhone 或 iPad 主畫面

Safari 目前不會顯示自動安裝視窗；依下列步驟加入後，DIJI 會以獨立 App 方式開啟。

  1. 在 Safari 點選底部的「分享」按鈕。
  2. 選擇「加入主畫面」。
  3. 確認已開啟「以 Web App 開啟」，再點選「加入」。
  1. 開啟 Chrome 或 Edge 的瀏覽器選單。
  2. 選擇「安裝 DIJI」或「將此網站安裝為應用程式」。
  3. 在瀏覽器的確認視窗選擇安裝。

對話、記憶與帳號資料仍保存在伺服器；離線時只能開啟介面，不能登入或傳送對話。
