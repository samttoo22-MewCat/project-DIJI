DIJI · 角色互動工作台

讓角色的每一次對話，都留在脈絡裡。

DIJI 是一個非商業、可自架的角色互動專案。它把角色人設、逐字對話、事件記憶與互動設定放在同一個清楚且可檢查的工作流程中。

開始前先選擇角色；每一段對話會維持各自的歷史與記憶脈絡。

角色先行

先選角色再開始對話，不以預設人格取代你的選擇。

對話可續

逐字歷史與事件記憶分開保存，讓後續互動有可追溯的前後文。

設定透明

模型、內容與互動設定都在對話內明確呈現，由你決定是否啟用。

非商業實驗專案 · 角色、歷史與設定依你選擇的流程保存。

安裝 DIJI

加入 iPhone 或 iPad 主畫面

Safari 目前不會顯示自動安裝視窗；依下列步驟加入後，DIJI 會以獨立 App 方式開啟。

  1. 在 Safari 點選底部的「分享」按鈕。
  2. 選擇「加入主畫面」。
  3. 確認已開啟「以 Web App 開啟」，再點選「加入」。
  1. 開啟 Chrome 或 Edge 的瀏覽器選單。
  2. 選擇「安裝 DIJI」或「將此網站安裝為應用程式」。
  3. 在瀏覽器的確認視窗選擇安裝。

對話、記憶與帳號資料仍保存在伺服器；離線時只能開啟介面，不能登入或傳送對話。
