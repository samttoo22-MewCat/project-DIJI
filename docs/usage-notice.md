# DIJI 使用須知

公開服務預設同時最多 8 個生成工作、每個帳號同時 2 個，每帳號每分鐘最多 20 次生成請求；生成工作預設 180 秒逾時，API 送出的資料上限為 1 MiB。超額需稍後再試，不會自動重送模型請求。逾時不代表模型商必定未計費，請先確認對話或草稿已保存的狀態，再決定是否重新生成。

越獄可保留系統預設，或編輯後另存自己的個人版本。個人版本只影響自己的帳號；刪除個人修改版會恢復對應的系統預設，純自訂項目則直接移除。此操作不會改寫已完成的聊天或生成流程紀錄。

## 1. 服務性質

公開網站先提供專案介紹；進入角色、聊天、建立角色、記憶與模型連線等工作區前，須使用 Google 登入。Google 登入用來建立 DIJI 帳號，不包含模型額度；登入後仍須連接自己的模型商才能生成角色與聊天。

DIJI 是非商業、自架的角色互動與文字生成實驗框架。它提供角色設定、對話、事件記憶、關係狀態與可選模型串接；它不是心理治療、醫療、法律、財務、緊急救援或事實查核服務。

模型輸出是自動生成文字，可能不正確、令人不適或不符合你的預期。請不要把輸出當成專業建議、事實證明或現實決策的唯一依據。

## 2. 年齡與成人虛構內容

你必須已達所在地法定成年年齡，才可使用可能出現成人虛構內容的功能。成人內容只限於虛構、成年人與合意情境；即使內容由模型生成，使用者仍須對輸入、設定與分享負責。

## 3. 禁止用途

- 涉及未成年人、未成年人形象或將未成年人性化的內容；
- 非自願、剝削、脅迫、性暴力或以現實傷害為目的的內容；
- 未經當事人同意使用真人身分、肖像、私密資訊或可識別特徵製作性化內容、冒充內容或騷擾內容；
- 侵犯著作權、隱私、人格權、名譽、商標或其他第三人權利的內容；
- 促成違法行為、惡意軟體、詐騙、跟蹤、仇恨、暴力威脅或規避資安控制的內容；
- 嘗試未經授權存取帳號、服務、金鑰、模型供應商或其他使用者資料。

## 4. 模型與供應商

實際模型請求只會在你明確啟用後進行。DIJI 預計提供 BazaarLink 與 OpenRouter 的 OAuth PKCE 連結，讓你以自己的供應商帳號與額度發送請求；這個連結是模型供應商授權，不是 DIJI 帳號登入。不同模型與供應商有各自的內容規則、可用性、速率與費用；供應商可能拒絕、限制或中斷某些請求。DIJI 不保證任何模型一定能產生特定內容，也不承諾或鼓勵規避供應商條款、平台規則或安全措施。

如果你連結 BazaarLink 或 OpenRouter，必須確保你有合法使用權限，並自行承擔該供應商帳號可能產生的費用。DIJI 不會為已連結使用者墊付模型費用，也不應把其他使用者的額度混用到你的請求。你可透過 DIJI 解除連結，並應能在供應商端撤銷授權。不要將 API key、密碼或存取權杖貼入對話內容、角色設定、公開 Issue 或截圖。

維運者得在合理必要範圍內限制、暫停或刪除違反本使用須知、危害服務安全、涉及未成年人或侵害他人權利的內容或帳號。這不表示維運者會對所有輸入或輸出進行即時人工審查。

## 6. 資料、備份與可用性

玩家訊息旁可按「編輯」，確認後「儲存並重新生成」。這會使用自己的模型商額度，從修改處建立新分支，不接續原回覆之後的情節；原對話可從「查看編輯前對話」開啟。新分支使用該回合前的記憶／關係／偏好快照；較舊對話若沒有這些快照，會保留前文並重新累積狀態，介面會說明。生成失敗時修改後的分支仍可能已保存，可再次編輯或繼續；取消編輯不會發送模型請求。

AI 修改助手中目前顯示的修改指令也可編輯；重新生成會從該指令執行前的草稿開始，而不是把之後的修改混入。結果另存新版本，後續內容可從草稿版本歷史恢復；這同樣使用自己的模型額度。

草稿停止輸入約 0.7 秒後自動同步；只有同步成功才算保存版本，網路中斷時請保留頁面並等待成功提示。可在「版本歷史與回滾」查看舊稿，再還原成新版本，回滾前內容仍保留。已儲存角色的舊稿會還原成另一份新草稿，不直接改動原角色。查看與回滾本身不會呼叫模型或產生模型費用；舊功能沒有留下快照的中間版本無法補回。版本歷史儲存在同一台伺服器，仍不等同異地備份。

「AI 修改助手」使用你選擇的模型與自己的額度，成功後會直接更新並同步角色草稿，請再次審核後才保存角色。收起視窗不會取消已發出的修改請求。模型可能誤解要求；若其他頁面已更新草稿，舊修改結果會被版本檢查阻擋，需重新讀取後再操作。

角色審核中的「測試對話」使用你自己的模型商額度，仍會產生模型費用。可隨時返回審核並保留修改內容，但返回不會取消已開始的請求；修改草稿後重新測試會開始新的試聊，避免舊試聊記憶影響結果。只有明確按下「儲存角色」才會加入角色庫。

伺服器會按帳號記錄角色生成各階段的輸入／輸出、失敗狀態、已完成草稿、保存角色與每輪對話。草稿修改同步成功後，可重新開啟建立角色頁繼續審核；確認保存才會加入自己的角色庫。流程紀錄不是公開角色，也不會出現在其他使用者帳號。程序意外停止可能留下未確認完成的紀錄，不代表模型已完成或可免費接續生成。更新前未保存的生成階段無法追溯補回。

對話、角色與記憶資料會依「使用者隱私條款」處理。雖然服務會採取合理措施維持資料與服務，仍可能因軟硬體故障、供應商變更、資安事件、維護或其他不可控制原因而中斷、遺失或無法存取。請自行保存重要的合法內容，且勿將 DIJI 當作唯一備份位置。
