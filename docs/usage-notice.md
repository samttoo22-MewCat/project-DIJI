# DIJI 使用須知

> 最後更新：2026-10-26
> 狀態：公開服務前的營運草案；與「使用者隱私條款」一併閱讀。

## 1. 服務性質

DIJI 是非商業、自架的角色互動與文字生成實驗框架。它提供角色設定、對話、事件記憶、關係狀態與可選模型串接；它不是心理治療、醫療、法律、財務、緊急救援或事實查核服務。

模型輸出是自動生成文字，可能不正確、令人不適或不符合你的預期。請不要把輸出當成專業建議、事實證明或現實決策的唯一依據。

## 2. 年齡與成人虛構內容

你必須已達所在地法定成年年齡，才可使用可能出現成人虛構內容的功能。成人內容只限於虛構、成年人與合意情境；即使內容由模型生成，使用者仍須對輸入、設定與分享負責。

## 3. 禁止用途

不得使用 DIJI 建立、要求、保存、散布或協助下列內容或行為：

- 涉及未成年人、未成年人形象或將未成年人性化的內容；
- 非自願、剝削、脅迫、性暴力或以現實傷害為目的的內容；
- 未經當事人同意使用真人身分、肖像、私密資訊或可識別特徵製作性化內容、冒充內容或騷擾內容；
- 侵犯著作權、隱私、人格權、名譽、商標或其他第三人權利的內容；
- 促成違法行為、惡意軟體、詐騙、跟蹤、仇恨、暴力威脅或規避資安控制的內容；
- 嘗試未經授權存取帳號、服務、金鑰、模型供應商或其他使用者資料。

## 4. 模型與供應商

實際模型請求只會在你明確啟用後進行。DIJI 預計提供 BazaarLink 與 OpenRouter 的 OAuth PKCE 連結，讓你以自己的供應商帳號與額度發送請求；這個連結是模型供應商授權，不是 DIJI 帳號登入。不同模型與供應商有各自的內容規則、可用性、速率與費用；供應商可能拒絕、限制或中斷某些請求。DIJI 不保證任何模型一定能產生特定內容，也不承諾或鼓勵規避供應商條款、平台規則或安全措施。

如果你連結 BazaarLink 或 OpenRouter，必須確保你有合法使用權限，並自行承擔該供應商帳號可能產生的費用。DIJI 不會為已連結使用者墊付模型費用，也不應把其他使用者的額度混用到你的請求。你可透過 DIJI 解除連結，並應能在供應商端撤銷授權。不要將 API key、密碼或存取權杖貼入對話內容、角色設定、公開 Issue 或截圖。

## 5. 內容與帳號責任

你保有你自行輸入內容中依法可主張的權利，並應確保你有權使用其中的角色、素材與資料。你授權 DIJI 在提供、保存、備份、資安防護與排除故障所必要的範圍內處理該內容。

維運者得在合理必要範圍內限制、暫停或刪除違反本使用須知、危害服務安全、涉及未成年人或侵害他人權利的內容或帳號。這不表示維運者會對所有輸入或輸出進行即時人工審查。

## 6. 資料、備份與可用性

對話、角色與記憶資料會依「使用者隱私條款」處理。雖然服務會採取合理措施維持資料與服務，仍可能因軟硬體故障、供應商變更、資安事件、維護或其他不可控制原因而中斷、遺失或無法存取。請自行保存重要的合法內容，且勿將 DIJI 當作唯一備份位置。

## 7. 條款變更與聯絡

我們可能因功能、法律、模型供應商或資安需求更新本使用須知。更新後的日期會標示在文件頂端。正式公開服務前，維運者必須在網站提供可私密聯絡的支援與隱私權請求管道；請勿以公開 Issue 提交個人資料或敏感內容。
