# DIJI 介面規範

沿用低彩度深藍、青色與個人角色的紫色識別。介面使用一致的面板層次、邊框與 12–22px 圓角；文字沿用既有放大字級，小字至少 16px。主要操作、鍵盤焦點、選中與危險操作必須能辨別。

## 各頁

- 首頁：主標與 Google 登入為焦點，對話情境標示為示意，下面介紹專案。
- 角色庫：人物卡片、清楚的名稱與摘要；自建角色保留私人紫色識別。建立角色卡在最後。
- 聊天：未選角只呈現前往角色頁按鈕。選角後沿用對話、左右抽屜、模型 gate、記憶與既有 prompt 流程。
- 建立角色：維持簡報、審核、保存三階段，欄位、步驟選中與生成中回饋一致。
- 記憶、越獄、設定、模型連線：共用面板、輸入框、按鈕與空狀態的視覺層次。

## 動態與操作

切頁淡入 240ms，抽屜與面板 220–280ms，滑鼠卡片上浮 3px。首頁線條只在進場時描繪一次；不增加背景循環動畫。正在生成沿用既有輸入泡泡，生成與用量更新有 busy 狀態。動畫不代表模型已成功回覆。

所有內容預設可見。`prefers-reduced-motion: reduce` 停用動態，偏好改變時取消首頁正在執行的 Web Animation。鍵盤 focus 保留 3px 外框，觸控目標至少 44px，手機不依賴 hover。

## 驗證
