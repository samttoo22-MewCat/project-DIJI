# DIJI 使用者隱私條款

> 最後更新：2026-11-01
> 狀態：營運草案。維運者須提供可受理隱私權請求的聯絡方式。已部署 BazaarLink／OpenRouter PKCE 連結，真實授權由使用者在供應商頁完成。

目前實作：模型連接憑證加密保存在伺服器帳號資料庫，額度順序依帳號保存。僅明確 HTTP 402 額度不足才轉至下一個已連接來源，該來源會收到必要模型請求資料。模型商卡片的「撤銷連接」會清除 DIJI 保存的該供應商憑證，保留登入、角色與費用紀錄；已開始的請求不會取消。若要讓供應商端金鑰失效，仍須至供應商金鑰管理頁撤銷。

## 1. 適用範圍與營運者

本條款適用於 DIJI 的網站、帳號、角色互動與相關支援服務。DIJI 是由 MewCat 維運的非商業、自架角色互動實驗專案。

本文件依目前公開程式的實作描述資料流，不是法律意見。若本文件與實際服務設定不一致，以較能保護使用者資料的處理方式為準，並應儘速修正本文件。

## 2. 我們處理的資料

依你使用的功能，DIJI 可能處理下列資料：

| 資料類型 | 來源與例子 | 用途 |
| --- | --- | --- |
| 帳號資料 | Google 登入回傳的帳號識別碼、顯示名稱與電子郵件 | 建立帳號、維持登入與隔離不同使用者的資料 |
| 登入狀態 | 隨機 session 的雜湊值與到期時間 | 驗證登入狀態與登出 |
| 你建立或輸入的內容 | 角色設定、對話訊息、場景、偏好與回饋 | 提供角色互動、保存你的對話與設定 |
| 衍生互動資料 | 事件記憶、關係狀態與使用者偏好檔 | 讓同一段對話維持上下文與選用的好感度功能 |
| 模型供應商連結資料（預計功能） | 供應商名稱、OAuth 授權流程中的暫時 state／PKCE verifier、供應商核發的存取憑證 | 讓使用者以自己的 BazaarLink 或 OpenRouter 額度發送模型請求 |
| 技術與安全資料 | 必要的服務錯誤、連線與維運紀錄 | 排除故障、防止濫用與維持服務安全 |

請不要在角色設定或對話中主動輸入身分證號、付款資料、密碼、醫療病歷、精確住址或其他不必要的敏感個人資料。內容可能被保存，也可能在你要求模型產生回覆時傳送給模型供應商。

## 3. 處理目的、方式與保存期間

記憶工作區提供單筆記憶的編輯與刪除。刪除只移除該筆事件記憶，不會刪除原始對話、其他記憶或已送至模型供應商的請求；目前沒有使用者可直接操作的回收桶或還原功能。原始對話仍可能提供相同資訊作為模型上下文。

公開部署的未登入訪客可閱讀專案介紹；角色、對話、記憶、越獄與模型連線工作區須先使用 Google 登入。登入狀態由伺服器驗證，未登入的工作區資料請求不會回傳內容。

我們只在提供登入、角色互動、記憶保存、帳號隔離、資安與維運所必要的範圍內處理資料。資料目前以服務端的帳號資料庫與使用者隔離的執行期檔案保存；對話逐字紀錄、事件記憶、關係狀態與使用者偏好不是同一種資料，也不互相取代。

資料原則上保存至你刪除相關內容、提出有效刪除請求、帳號終止，或上述處理目的消失為止。因資安、爭議處理或法律義務必須保留的資料，會在必要期間內以受限方式保存。DIJI 不應將使用者內容拿來做廣告受眾建立或出售給第三方。

使用者 OAuth 連結功能上線後，PKCE verifier 與 state 只會在完成或失敗的授權流程所需期間內保存；供應商核發的存取憑證只會以伺服器端受保護的方式保存，不會回傳到瀏覽器、不會寫入日誌，也不會被顯示給其他使用者。使用者中斷連結、撤銷授權或帳號刪除後，DIJI 應刪除仍保存的連結憑證；供應商端的撤銷與費用狀態則由該供應商控制。

## 4. 第三方服務與跨境傳輸

DIJI 可使用以下類型的第三方服務：

- **Google**：僅在你主動使用 Google 登入時，用於 OAuth 登入與身分識別。
- **BazaarLink 與 OpenRouter（預計使用者 OAuth 連結）**：使用者可選擇透過 OAuth PKCE 授權 DIJI 代為使用自己的供應商額度。DIJI 不會取得使用者的供應商密碼，也不會以 DIJI 的共用額度替代已連結使用者的額度。當你明確啟用實際模型請求時，服務會傳送生成回覆所需的訊息、角色與必要上下文；供應商可能位於臺灣以外地區，並依其自身條款處理資料。
- **雲端基礎設施供應商**：公開服務的帳號與內容資料可能儲存在維運者選定的雲端地區。

我們不會因為你僅瀏覽介紹頁面就把角色對話內容送至模型供應商。是否發送實際模型請求，應由介面清楚顯示並由你主動啟用。OAuth 連結是模型供應商的付款／請求授權，不應被描述成 DIJI 帳號登入或身分驗證。

## 5. 資料安全

DIJI 採取與服務規模相稱的存取控制、帳號隔離、權限設定與傳輸保護措施；例如 session 僅保存雜湊值，執行期帳號與使用者資料應限制檔案存取權限。任何網路服務都無法保證絕對安全；若發現資料遭未授權存取、竄改、毀損、遺失或洩漏，維運者應採取合理的應變與通知措施。

## 6. 你的權利與請求方式

依適用的個人資料保護法令，你可請求查詢或閱覽、取得複製本、補充或更正、停止蒐集／處理／利用，以及刪除你的個人資料。提出請求時，維運者可能需要合理驗證你的身分與帳號權限，避免他人冒用。

正式公開前，網站必須公布可私密受理請求的聯絡方式；請不要在公開 GitHub Issue 或公開聊天室張貼帳號、對話或其他個人資料。使用者可在 DIJI 解除供應商連結，並應可在 BazaarLink 或 OpenRouter 自身的帳號頁撤銷相應的授權。臺灣使用者可參考[個人資料保護法](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=I0050021)第 3 條所列權利。

## 7. 未成年人

DIJI 的角色互動可能含有成人虛構內容。未達所在地法定成年年齡者不得建立帳號、使用服務或提供個人資料。維運者得在合理必要範圍內要求年齡或資格確認，並對疑似未成年帳號採取限制或刪除措施。

## 8. 條款更新

當帳號機制、保存位置、模型供應商、用途或安全措施有重大變動時，維運者會更新本文件的日期與內容。重大變更應在生效前以網站公告或其他合理方式告知。
